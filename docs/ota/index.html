Bluetooth update and settings

Display for the Timemore Black Mirror Dot · project on GitHub

This browser has no Web Bluetooth. Use Chrome or Edge on a computer or Chrome on Android. On iPhone, open this page in the Bluefy app.
  1. On the device: 3 clicks → Update (BLE). The screen shows a PIN.
  2. Type the PIN below, then use any of the sections.

Clock and Wi-Fi

The device has no battery-backed clock. Set it from this phone or computer now, and optionally save your Wi-Fi: then it gets the time by itself at power-up (Wi-Fi is used only for a few seconds, before Bluetooth starts, and then switched off).

Firmware update

Download firmware.ino.bin from the latest release.

Protocol: service c0de0001-7d2e-4b5a-9c1e-0a7e5d0f0a01, version 2. Documented in firmware/70_ota.ino.
