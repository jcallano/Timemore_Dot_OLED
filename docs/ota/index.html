Actualizar por Bluetooth

Display para la Timemore Black Mirror Dot · proyecto en GitHub

Este navegador no tiene Bluetooth web. Usa Chrome o Edge en un ordenador o Chrome en Android. En iPhone, abre esta página con la app Bluefy.
  1. Descarga el firmware: el archivo firmware.ino.bin de la última versión.
  2. En el aparato: 3 clics → 7. Actualizar (BLE). La pantalla muestra un PIN.
  3. Elige el archivo, escribe el PIN y pulsa Actualizar.

Protocolo: servicio c0de0001-7d2e-4b5a-9c1e-0a7e5d0f0a01, versión 1. Documentado en firmware/70_ota.ino.
